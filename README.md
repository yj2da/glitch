> **최신 인터랙티브 웹 디자인, 마이크로 인터랙션, 글리치(Glitch) 이펙트 및 다이내믹 UI를 실험하고 구현하는 프론트엔드 랩 프로젝트**

🔗 **라이브 데모:** [glitch-ruby.vercel.app](https://glitch-ruby.vercel.app)

---

## 📌 Key Features

- **모던 인터랙션 디자인**: 사용자 인터랙션에 반응하는 다이내믹 시각 효과 및 마이크로 애니메이션.
- **Next.js & Tailwind CSS**: 컴포넌트 기반 아키텍처 및 고성능 렌더링 최적화.
- **반응형 레이아웃**: 모든 디바이스에서 매끄럽게 동작하는 모바일/데스크톱 반응형 뷰.

---

## 🛠 Tech Stack

- **Framework**: Next.js, React
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
